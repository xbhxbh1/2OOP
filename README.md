# Python tasks

Чотири консольні програми на Python 3.

| Файл | Завдання |
|------|----------|
| `task1_leap_year.py` | Перевірка, чи рік високосний (кожен 4-й - так, кожен 100-й - ні, кожен 400-й - так) |
| `task2_triangle.py` | Трикутник заданої висоти з числами (рядок `n` містить число `n` рівно `n` разів) |
| `task3_millionaire.py` | Гра «Хто хоче стати мільйонером» (5 питань, 4 варіанти відповіді, +100 балів за кожну правильну) |
| `task4_calculator.py` | Калькулятор: `5 + 5 * 10 + 4 / 2 - 3` -> `54` |

Запуск:

```
python task1_leap_year.py
```
